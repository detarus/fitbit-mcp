# fitbit-mcp 0.1.0-alpha.4

- Add a Claude Desktop local MCP installer for macOS/Windows, preserving other configuration, backing up existing JSON and rejecting conflicting entries.
- Expose shared setup, review and nutrition instructions as MCP prompts. Fix setup skill documentation links when copied outside the repository.
- Harden existing local state: reject symlinks/hardlinks/nonregular files, repair POSIX modes, and remove explicit Windows ACL grants before use.
- Add synthetic coverage for cancellation, date-separated meals/water, permission removal, linked water correction, Desktop configuration and storage restrictions.
- Document all 14 read types, current chat-client connection options and every remaining roadmap dependency.

Download the tarball and SHA256SUMS from this release; verify the checksum, then:
```sh
npm install --global ./detarus-fitbit-mcp-0.1.0-alpha.4.tgz
fitbit-mcp demo-check
fitbit-mcp install --client claude-desktop --demo
```
The last command is for macOS/Windows Claude Desktop. Restart the app and request fitbit_status; it should report demo. [Full setup](https://github.com/detarus/fitbit-mcp/blob/main/docs/desktop.md), [CLI/update/removal](https://github.com/detarus/fitbit-mcp/blob/main/docs/installation.md).

Release publication is gated by synthetic tests, installed-tarball checks and actual Codex/Claude Code registration on macOS/Windows/Ubuntu. This does not verify the Desktop UI, Google OAuth/account writes, real photographs or Fitbit Air parity. Those acceptance tasks remain open. Node.js 24 is required; npm registry publication and remote web/mobile transport are not included.
