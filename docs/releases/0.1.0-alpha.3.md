# fitbit-mcp 0.1.0-alpha.3

Local Fitbit MCP for Codex and Claude Code, Apache-2.0. This prerelease is for testing; real-account validation is pending.

New: personal-relative recovery v1, SpO2/respiration/skin delta, stable write IDs, read-only reconciliation, linked meal/water corrections, and one-command MCP + skill installation.

Download the .tgz and SHA256SUMS, verify the checksum, then install with Node 24:
```sh
npm install --global ./detarus-fitbit-mcp-0.1.0-alpha.3.tgz
fitbit-mcp demo-check
fitbit-mcp recovery --demo --date 2026-10-17
fitbit-mcp install --client codex
fitbit-mcp install --client claude
```

[Installation and updates](https://github.com/detarus/fitbit-mcp/blob/main/docs/installation.md) · [Mac OAuth test guide](https://github.com/detarus/fitbit-mcp/blob/main/docs/TESTING.ru.md) · [Compatibility](https://github.com/detarus/fitbit-mcp/blob/main/docs/compatibility.md) · [Recovery formula](https://github.com/detarus/fitbit-mcp/blob/main/docs/recovery.md)

Recovery is a custom unvalidated wellness heuristic, not Fitbit's score or a medical assessment. A normal personal baseline is not proof of healthy sleep or fitness to train. Corrections delete originals then save replacements and are not atomic. Interrupted writes must be reconciled using their existing IDs.

The release job runs only after OS checks and client configuration checks succeed. All test records are synthetic; Google access, consent and diary presentation still require the account owner. No secrets, health records or meal photos are included. No npm registry publication.

Keep private journals when updating. Finish active corrections before downgrading; older versions do not enforce correction links.
